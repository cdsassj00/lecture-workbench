## 구성

- `index.html`: 회차 목록
- `session-01-complete.html` ~ `session-08-complete.html`: 회차별 완성 슬라이드
- `references.html`: 자료 목록
- `assets/images/`: 원본 슬라이드에 포함된 이미지
- `assets/refs/`: 기존 파일 저장소에서 옮긴 자료
- `static/`: 읽기 전용 화면 스타일·슬라이드 탐색
- `curriculum.html`, `assignments.html`: 기존 과정·실습 안내
