ChatGPT 고급 기능 — Projects와 Custom GPTs
ChatGPT에서 먼저 살펴볼 두 가지 고급 기능입니다. 첫째, Projects는 대화·파일·지침을 하나의 프로젝트로 묶어 두는 작업 공간입니다. 프로젝트에 올려 둔 파일은 이후 모든 대화에서 자동 참조됩니다. 둘째, Custom GPTs는 시스템 프롬프트·파일·Actions를 묶어 재사용하는 '나만의 GPT'입니다. 부서 업무에 맞는 챗봇을 만들어 동료에게 공유할 수 있습니다. 두 기능 모두 개인용이 아니라 부서 단위로 설정해 사용합니다.
FEATURE 01 · PROJECTS
채팅 · 파일 · 지침을
하나로 묶는 작업 공간
프로젝트 안에서는 대화 간 맥락이 자동 유지됩니다. 파일을 올려두면 이후 모든 대화가 그것을 참조합니다. 부서 지침 · 샘플 보고서 · 금칙어 세트를 한 프로젝트에 두면 동료가 진입 비용 없이 같은 기준의 답변을 받습니다.
질문 템플릿 5개를 고정 메시지로 상단에 배치하고, 주 1회 업데이트 담당자를 정해두면 자산이 됩니다.
FEATURE 02 · CUSTOM GPTs
시스템 프롬프트 + 파일 + Actions
= 재사용 단위 "나만의 GPT"
GPT Store에서 다른 사용자가 만든 것도 가져다 쓸 수 있습니다. 공공에서는 "민원 분류 GPT" · "예산 검토 GPT" 같은 업무 특화 GPT를 거점리더가 만들어 부서에 배포합니다. Actions는 외부 API 호출 기능이지만 8차시 MCP로 대체되는 방향입니다.
Custom GPT는 좋은 프롬프트를 묶어 동료에게 공유하는 가장 빠른 방법입니다.
DEPLOYMENT LENS
부서 단위로
운영하는 이유
Projects와 Custom GPTs를 개인 도구로만 사용하면 본인만 활용하게 됩니다. 부서 단위로 설정해 두면 동료가 같은 환경에서 같은 기준의 답변을 받을 수 있습니다. 부서 지침 PDF, 샘플 보고서 3건, 금칙어 목록을 한 프로젝트에 미리 올려 두는 데 약 30분이 걸립니다.
민감 파일 업로드는 주의해야 합니다. OpenAI 서버에 저장되므로 감사·분쟁 소지가 있는 문서는 비식별화 후에 사용합니다.

SECTION 1Custom GPTS의 메모리 기능
Custom GPTs의 메모리 기능 

커스텀 GPTs를 활용함에 있어서 가장 중추적인 역할을 하는 것은 바로 '메모리' 부분입니

심화 기능
메모리
Custom GPTs는 대화 내용을 기억하는 메모리 기능을 제공합니다. 사용자가 이전 대화에서 입력한 선호 사항, 작업 방식, 반복 요청 패턴을 저장하여 다음 대화에서 자동으로 반영합니다. 메모리 기능의 작동 방식은 다음과 같습니다.

첫째, 사용자가 특정 정보를 입력하면 GPTs가 중요한 내용을 자동으로 메모리에 저장합니다.
둘째, 다음 대화 시작 시 저장된 메모리를 불러와 맥락을 유지합니다.
셋째, 사용자가 명시적으로 "이것을 기억해 주세요"라고 요청할 수도 있습니다. 메모리에 저장되는 정보는 작업 형식, 출력 스타일, 자주 사용하는 도구명, 프로젝트 배경, 금지 표현 목록 등입니다.

예를 들어 "존댓말로 작성", "비유 표현 금지", "첫째·둘째 열거 사용" 같은 규칙을 한 번 설정하면 이후 대화에서 반복 지시 없이 자동 적용됩니다.

ChatGPT의 다섯째부터 일곱째 고급 기능입니다. 첫째, GPT-5.5 Thinking은 답을 바로 생성하지 않고 내부 추론 과정을 거치는 reasoning 모델입니다. 단순 다음 단어 예측이 아니라, 중간 사고 단계(Chain of Thought)를 만들고 검증하며 답을 개선합니다. 둘째, Memory는 사용자 업무 맥락과 선호를 장기 기억해 이후 응답에 반영합니다. 셋째, Deep Research는 여러 자료를 탐색·비교·검증해 구조화된 보고서를 자동 생성합니다. 최근 AI는 “빠른 생성”보다 “추론·도구 사용·멀티스텝 작업” 중심으로 발전하고 있습니다.
KICK 05 · GPT-5.5 THINKING
단순 생성이 아니라 “중간 사고 과정”을 학습하는 추론 모델
기존 GPT는 다음 단어를 빠르게 예측하는 방식이었다면, 최신 reasoning 모델은 문제를 여러 단계로 분해하며 중간 추론 과정을 생성합니다. 이를 Chain of Thought(CoT)라고 부릅니다.

추론 모델은:

  • 중간 사고 단계를 길게 생성하고
  • 스스로 오류를 검토하며
  • 여러 풀이 경로를 비교하고
  • 강화학습(RL)으로 더 좋은 사고 과정을 학습합니다.

최근 GPT-5.5 계열은 추론 토큰(reasoning tokens)을 사용해 답변 전에 내부적으로 “생각 시간”을 사용합니다.

CoT(Chain of Thought) + RL(Reinforcement Learning) + Test-Time Compute가 최신 추론 모델 핵심 구조입니다.
KICK 06 · REINFORCEMENT LEARNING
“정답”만이 아니라 좋은 사고 과정 자체를 강화학습 

최신 추론 모델은 단순 다음 단어 예측을 넘어서,
중간 사고 과정(Chain of Thought)을 더 잘 만들도록 강화학습(RL)을 수행합니다.

모델은:

  • 여러 풀이 경로를 생성하고
  • 어떤 사고 과정이 더 정확했는지 평가받고
  • 좋은 추론 패턴에 보상을 받으며
  • 스스로 오류 수정 전략을 학습합니다
RL + Chain of Thought(CoT)가 최신 reasoning 모델 핵심 학습 방식입니다.
KICK 07 · DEEP RESEARCH
답변 전에 더 오래 생각하며 추론 성능을 높이는 구조

최근 reasoning 모델은 답변 생성 전에 내부적으로 긴 사고 과정을 수행합니다. 이를 Test-Time Compute(TTC)라고 부릅니다.

복잡한 문제일수록:

  • 더 긴 추론 토큰 생성
  • 중간 검토
  • 자기 검증
  • 다른 풀이 재시도

과정을 수행하며 정답률을 높입니다.
